# v0.7.0 — Jernie, redesigned

This release moves the native app onto its new visual and interaction foundation and carries
the redesign through Home, Agenda, itinerary, detail sheets, and Explore. It contains 41 feature
commits since `v0.6.1-profile`, touching 264 files with 26,700 additions and 5,229 deletions
before the release-preparation commit.

## Design system and app foundation

- Adopted the shared Jernie design system: six bundled static font faces, light and dark theme
  palettes, tokenized type/spacing/motion/elevation, Phosphor icons, and the twelve reusable UI
  primitives.
- Added the shared photo resolver/rendering seam so screens no longer own image URLs or fallback
  behavior.
- Added haptics, FlashList, Expo Image, Phosphor, and SVG support. iOS builds React Native from
  source so third-party Fabric codegen is linked correctly.
- Fixed the full Jest command so an all-pass run now exits successfully instead of failing during
  asynchronous teardown.

## Home, Agenda, and details

- Rebuilt Home as one continuous scroll surface with the collapsing photo header, stop rail,
  stop morph, phase-aware calls to action, and grouped trip content.
- Added Agenda's three lenses, four itinerary type groups, pure derived gap detection, inline gap
  prompts, and the coverage grid.
- Replaced the duplicated entity sheets with one data-driven detail shell and composable blocks
  for every supported booking and itinerary type.

## Continuous itinerary timeline

- Replaced the old itinerary accordion with a multi-day timeline, compact date rail, meaningful
  time bands, transition-day semantics, gap context, and unscheduled items.
- Swipe actions always expose Details and only expose Navigate when the record has a destination.
  Navigation can open Apple Maps, Google Maps, or Waze, with a remembered preference.
- Removal uses a confirmation sheet and delayed commit: Undo cancels the queued deletion instead
  of trying to recreate a record after it has already been removed.
- Long-press reorder supports same-day and cross-day moves, precise above/below insertion lines,
  live time-band feedback, edge autoscroll, locked-item confirmation, and authenticated atomic
  writes. The lifted row and post-drop layout settle remain smooth across day boundaries.

## Explore

- Lifted Explore filters into a shared trip-level store that the upcoming Map tab can consume.
- Stop selection defaults to the current, next, or final trip stop instead of an unhelpful global
  result set.
- Rebuilt the screen around one filter bar, one featured carousel, a two-column result grid,
  ChipDropdown, and a draft-then-Apply filter sheet.

## Verification

- `npm test`: 91 suites, 1,084 tests, and two snapshots; exit 0.
- `npx tsc --noEmit`: clean.
- Cold Expo SDK 56 iOS export: clean at 2,624 modules.
- Same-day and cross-day drag/drop, edge autoscroll, smooth geometry settlement, and reduced-bounce
  tuning were confirmed on an iPhone.
- After a fresh native build, installed Google Maps and Waze are both discovered and launch
  correctly on an iPhone.

## Release boundaries

- Explore's full device pass is still open.
- The itinerary's broader Task 7 review remains open for both themes, Dynamic Type, VoiceOver and
  non-gesture alternatives, reduced motion, locked-write rollback, and long-trip performance.
- Destination-day-wide drag tint and a fully empty remote Unscheduled drop target remain deferred.
- Google Maps and Waze discovery depends on native query-scheme configuration in this release and
  therefore needs a fresh development build; an OTA update alone cannot enable it.
