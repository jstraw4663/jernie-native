The shipped wizard asks for a trip name before it has given anything, then asks you to sign in twice. This one starts with the destination, creates the trip locally on step one, and only asks for an account once there is something to lose. Passwords are gone: Apple, Google, or a link in your email.

Collision case
Someone builds a trip anonymously, then signs in with an Apple ID that already has trips. The existing code handles this with an adopt prompt. Keep it, but only show it when the anonymous side has something in it — a trip with at least one stop. Otherwise sign in silently.
