01 Screen by screen

Each screen with the decision that produced it and the interaction rules that go with it. Option ids refer back to the exploration file.

1b + 2a Jernie · home

Where am I, what's next, what's broken.

Decisions
Photo hero carries the place; the stop rail is a white card lifted off it rather than an overlay, so text never fights the image.
Dots are the only swipe affordance on the rail. No arrows, no peek of the next card — the dots plus the card edge were enough in review.
Today's items are rows, not cards, because they're a queue rather than a gallery. Gaps appear inline in amber, using the same row shape as Agenda.
Interaction
GestureResult
Scroll 0→140Photo re-crops in place (no translate, so no black band), rail widens to full bleed and pins as the header
Swipe railChanges stop; hero photo cross-fades, item list re-queries. Does not change the trip date.
Tap rowDetail sheet at medium detent over the current screen
6b Explore

Find something worth adding, near where you'll actually be.

Decisions
One filter bar, not two rows. Stop and type are dropdown bubbles because they're always set; everything else hides behind the icon with a count.
Stop defaults to where you are, or the next stop if you're between them. Explore is never "anywhere" unless you have no trip.
Carousels above, grid below: the carousel is editorial, the grid is exhaustive. One carousel maximum per screen.
Interaction
Tap bubbleInline dropdown, not a sheet. Selection applies immediately, no Apply button.
Tap filterFull sheet with Apply, because multi-select needs a commit point
Filter stateShared with Map. Switching tabs keeps the same result set.
7 Map

The trip as geography, with two modes on one surface.

Decisions
Route mode is the default and shows only booked items. Explore mode recesses the route to a faint line and surfaces place markers.
One sheet serves both modes — the list re-queries, the sheet doesn't rebuild. Detent position survives the mode switch.
Marker hierarchy is size, not colour: current location largest, booked items medium, suggestions small and outlined.
Interaction
Tap markerSheet snaps to medium and scrolls that item into view, marker scales up
Drag sheetThree detents: 120px peek, 55% medium, near-full. Map recentres to keep the active marker visible.
Mode switchRoute line fades to 25% opacity, place markers fade in over 200ms. No camera move.
5 Detail sheet

One shell, four content types, thirteen blocks.

Decisions
The shell owns detents, hero, title, and the footer action. Everything between title and footer is a block from the library.
Each type declares its blocks in order: Restaurant, Stay, Activity, Travel. Adding a fifth type is a list, not a new screen.
The footer action is always primary and always the same shape, so the sheet has one obvious exit into the itinerary.
Block order by type
RestaurantStats · Description · Tags · Hours · Location · Reviews · Nearby
StayBooking · Stats · Amenities · Description · Location · Check-in
ActivityDifficulty · Stats · Description · Conditions · Location · Nearby
TravelBooking · Timeline · Confirmation · Location · Documents
9b + 9c Agenda

Not "what's next" — "what's missing".

Decisions
Grouped by type, chronological inside, stop as the second line. By day and By stop re-slice the same rows — one dataset, three lenses.
Gaps are rows with their own Add, not absences. Derived by comparing each stop's date span against bookings of that type.
The coverage grid from 9c appears only when there's at least one gap: worth 200px when something's wrong, nothing when it isn't.
Amber, never red. Unfinished is not broken; red is reserved for a cancelled booking.
Gap rules
Stay gapAny night inside a stop's span with no booking covering it
TransportA stop with no arriving booking and no car whose window covers it
Never a gapEating and doing — preferences, not requirements. Their sublines only count.
DismissalPer stop, per trip — "we're driving with friends" shouldn't silence future trips
10c Profile · passport

The record of your travelling, not the drawer of your preferences.

Decisions
Photo header reuses the home hero treatment, so the tab belongs to the app instead of reading as a system screen.
Four counts and past trips are the content. Settings collapse into three rows and a gear.
Trip switcher is a row that opens the full trip list, not a set of cards.
Companions get their own screen behind the row — contribution per person, invite state, and a one-sentence permission rule.
Settings hierarchy
Set onceUnits, currency, language — row with current value, opens a picker
Flipped oftenTheme — inline control, no navigation
Own screenCompanions, notifications, account
DemotedHelp, sign out. Delete account lives inside account, never on this screen.
02 Tokens

Dark values are warm charcoal, not inverted greys — the neutrals hold a little of the photography's warmth so images sit in the surface rather than on it. Teal and amber both lift in dark mode to hold contrast against a darker field.
