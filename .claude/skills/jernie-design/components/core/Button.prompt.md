Use for the single committing action on a screen or sheet — never two primaries in one view.

```jsx
<Button label="Add to Itinerary" variant="primary" icon={<PlusIcon />} />
<Button label="Save later" variant="ghost" size="md" />
```

Footer buttons are `lg` and full width. `sm` is the 30px pill that lives inside a row ("Add", "Fix", "Book"). `dark` exists only for Apple sign-in; use `secondary` for Google and email.
